## 顺序步骤

1. 先打开A07交付的docs/project/checklists/D02.md，按表定位suite.json、schema、evaluation-config与审批登记；没有实际文件或批准范围不足，记录具体案例并停止相关项。
2. 逐例检查原文、回答、目标记录、来源与预期事实相互一致；空缺、否定、不适用、冲突不能互换，T06 金额按给定币种／状态核对。
3. 检查角色／指引编号版本、权限、必须条件、允许未知和接收方正文；T14／T15 的负向配置不应被正常选为有效业务配置。
4. 核对每项交互变体都有固定动作、预期和禁止事项，检查 T09 的200与250是不同操作场景；禁止把真实模型输出复制成预期。
5. 在本卡逐例记录一致／差异／未检查及路径，交 A 修正；重跑 npm run check:business。不得修改批准登记或自行增加业务规则。
