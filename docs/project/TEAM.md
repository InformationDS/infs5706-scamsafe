# 小组成员与工作范围

GitHub 用户名、负责人及审核人尚未提供，不预设成员人数或身份。

| 工作范围 | 主要交付 | 负责人 | 审核人 |
|---|---|---|---|
| 产品与契约 | PRD、字段、schemas、兼容性 | 待分配 | 待分配 |
| 指引与评估 | 合成权限、指引、15 个案例和预期结果 | 待分配 | 待分配 |
| 界面交互 | 双栏工作台、事实核对、聊天补问 | 待分配 | 待分配 |
| 分析服务 | 模型、提取、分类、补问与多机构建议 | 待分配 | 待分配 |
| 记录与输出 | 本地历史、审核版本、交接、双格式输出 | 待分配 | 待分配 |
| 集成与验收 | 全流程测试、失败记录和复测 | 待分配 | 待分配 |

一名成员可以承担多个范围；同一交付的审核安排由团队确定。并行开发前先完成共享契约。当前任务列表见 [TASKS.md](TASKS.md)。
