# 文件交付清单模板

复制到local/delivery/本卡编号/MANIFEST.md后填真实值。此处不维护另一份状态或通过结论。

```text
任务编号：[本卡编号]
工作包编号：[A发放编号]
基础副本编号：[A发放完整副本编号]
实际操作者与系统：[实际值]
本机工作路径：[实际绝对路径]
唯一执行记录：[本任务卡或A明确切换的Issue]

本次文件：
项目相对路径 | 发放SHA256或本卡创建 | 具体变化
[实际路径] | [A提供基线] | [具体修改]

本次证据：
[项目内证据路径] -> [交付目录内对应路径]

缺失或未交付项：[具体内容；没有写无]
```

说明例：B01交付shared/intake.ts和本模块界面，文件行分别填写新建身份或真实基线；证据索引到本次更正200及部分回答的实际观察。实际检查结论填B01卡，不再复制到本清单。本例不表示任务已执行。
