## 顺序步骤

1. 在/?module=guidance用固定T09事实与实际批准包开始；先核对岗位、接收方、EX-G01–03 v1及来源，不改批准内容或哈希。
2. 实现机构／岗位选择、权限边界与确定性指引匹配；检查批准、有效性、必须满足、允许未知、冲突及来源，不能只靠类型名称命中。部分缺依据仅省略对应步骤并解释。
3. 实现相关机构／本岗位事项、优先级与依赖展示，简单风险关注提示仅用A01已审阅触发条件；未核对与依据失效清楚标注，不评分。
4. 完成建议接受／修改／拒绝、理由和Employee edited历史；拒绝不删事实，重算不自动撤销选择。输出受影响建议版本与依赖信息，由E更新关联输出。
5. 实现角色／指引变更，事实、首次核对历史及计数不重置；无有效依据时返回固定英文提示及仅事实摘要资格，不生成机构路径或交接建议。完成本模块UI和事件绑定，不等待其他模块。
6. 运行npm run check:business、npm run check、npm run build及guidance模块检查；交回实现和固定匹配／拒绝／失效结果。需扩业务内容时先交A审阅，不自行刷新批准登记。
