3. 独立检查无指引摘要、人工更正保护、3轮9问／重试、拒绝传播、角色权限、单稿编辑失效、保存刷新及原型实际提供的失败入口。不要从页面结果反推标准答案。
4. 检查演示采用的真实模型时，由人类主动调用，记录实际结果；mock、真实、失败及未执行分开。完整T01–T15作为扩展覆盖可按已准备输入继续检查，不因未准备而阻塞第一轮原型报告，不声称全范围通过。
5. 把问题集中编号为F01-001等，记录最短输入／动作／预期／实际／证据及所属模块。一次提交汇总，A统一分派；F不改产品实现或验收标准。报告包含失败仍可被接收，供F02进入复测。
