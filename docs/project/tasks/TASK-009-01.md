## 目标与开工条件

核对已有银行与电信目标稿装配表及最小标题示例，补充排版说明，不改案例事实和规则。A 填好上述分配信息后可用教学正文准备；这不是已经导出的已审核案件。

## 读取与修改范围

- 读取：[完整样例](../../product/examples/WORKED_CASE.md) 第4.1、5–7节；[PRD](../../product/PRD.md) 对应条款。
- 可修改现有[排版起始稿](../../product/EXPORT_LAYOUT.md)：只补标题、顺序、分页说明和固定正文核对记录。保留教学标识，不修改来源正文。
- 更新本卡执行结果或对应 Issue。

## 输入与步骤

1. 按起始稿装配表定位样例第6节的共用元信息、Shared summary及对应接收方段落。沿用本稿的装配表和最小标题示范，仅核对顺序、对应正文与文案位置；不复制两份完整正文。
2. 补充起始稿的标题层级、案件／版本／接收方、摘要和未知项的位置说明，以及PDF的换页与长文本要求。
3. 版本使用明显占位并注明实际运行时替换为具体整数；不要把示例标成实际已审核导出。
4. 比较银行与电信样稿中的金额、时间、疑似类型、未知项和拒绝建议处理，确认与原文一致。保留原始2000仅作为更正历史，当前金额为200。
5. 由 B 检查标题和接收方是否易于辨识，F核对内容是否遗漏。此阶段不装PDF库、不新建保存或审核逻辑。

## 人工检查与完成条件

在Markdown预览中对照装配表与唯一正文：无指引摘要及有指引两份目标稿的正文引用正确；接收方位置清晰；合成和本地草稿标识可见；拒绝的建议未作为待执行动作。B／F完成展示和内容核对后交A验收文稿。没有真正生成PDF时，分页和中文渲染只能写“待运行检查”。

## 停止与反馈条件

为排版需要改写事实、去掉未知项、调用模型重写正文或更改审核规则时交 A。缺少PDF生成入口是后续实现依赖，不要求本任务代做。
