## 顺序步骤

1. 启动A01发放的/?module=intake，使用固定分析替身，按prototype.json独立加载T09；记录接收模块的具体函数／回调，不自行定义第二套案件状态。
2. 实现自由描述输入、来源记录、事实／候选类型展示、更正、冲突候选及首次核对；金额2000→人工200后重读原文不覆盖人工值。按币种／交易状态汇总，多笔交易答案不串位，未知不变成否或0。
3. 实现当前轮问答、部分回答、未知／无法回答／不适用、结束及后补答案；字段＋记录目标和问题ID稳定。展示并保存成功才计数，失败重试不重复；3轮9问和未知不重复问由程序控制。
4. 完成本模块界面、样式和事件绑定；首次核对后直接变更需确认，正常补问更新在最终审核处理。通过A01命令端口返回状态变化及失效信息，不在本模块匹配指引或生成草稿。
5. 用固定正常／无效／延迟分析返回检查失败与人工保护；模型端口可换成C实现但不等待它。不改A主页面、公共schema或全局CSS。
6. 运行npm run check、npm run build和A01实际验过的intake模块检查；交回完整模块、固定操作和结果。后续集中修复仍追加本卡批次，不另开展示卡。
